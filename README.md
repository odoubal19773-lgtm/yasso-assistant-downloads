On Android, download and open the APK; allow installation from your browser if Android asks. Export a backup before updating. Install over the existing app; do not uninstall, because uninstalling removes local data.

Android 8 or newer. Version 1.0.1 keeps the application identity and signing certificate from 1.0.0. Voice uses the phone's system speech service when available. ChatGPT opens externally; built-in general AI is not connected. Native reminder delivery, speech and upgrade behavior still need a real-phone test. Notifications require Android permission and enabled reminder settings; power-off, force stop and battery restrictions can block or delay alerts.
